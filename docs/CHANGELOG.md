# Changelog

All notable changes to this project will be documented here.

The format follows Keep a Changelog and the project uses semantic versioning once releases begin.

## [0.1.0] - 2026-07-28

### Added

- Next.js frontend with landing page, dashboard, wallet search, wallet details, portfolio, token holdings, NFTs, transactions, airdrop, risk, settings, profile, notifications, AI insights, 404, and error states.
- NestJS backend with wallet, portfolio, airdrop, auth, and health modules.
- Shared TypeScript package for types, constants, validators, and utilities.
- Blockchain package with Viem-based service structure.
- Prisma schema for wallet intelligence workflows.
- Redis cache integration.
- Docker Compose stack.
- GitHub Actions CI workflow.
- Professional README, documentation set, repository templates, and concept preview assets.

### Changed

- Clarified implemented versus planned modules across README, docs, and UI.
- Improved frontend visual system, metadata, dashboard density, and responsive layout.

### Security

- Documented responsible disclosure and production security checklist.
