## Repository Description

Production-minded Web3 intelligence platform for wallet analytics, portfolio tracking, airdrop eligibility research, and on-chain risk analysis.

## About Section

Web3 Intelligence Platform is an open-source Turborepo built with Next.js, NestJS, Prisma, PostgreSQL, Redis, Viem, Wagmi, and RainbowKit. It provides wallet search, portfolio analytics, airdrop scoring, and professional concept surfaces for planned risk, NFT, transaction, notification, and AI modules.
